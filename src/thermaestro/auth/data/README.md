# Common passwords

`common-passwords.txt` holds the entries of 8 characters or more from SecLists'
`Passwords/Common-Credentials/10k-most-common.txt` (sha256 of the source file
`68782d6a4a19a4768d5f15dd66bd534e7a33055cc755411e33f16d18c50fdcce`), sorted, one per line.
Thermaestro refuses them as passwords.

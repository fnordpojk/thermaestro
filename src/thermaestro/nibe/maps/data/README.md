# Nibe register tables

`bus.json` (models on the MODBUS40 accessory bus) and `s-series.json` (S-series over Modbus TCP) are generated by `scripts/make-registermaps.py`. Don't edit them by hand. Every register names the sources it comes from, and keeps what another source says where that differs.

## Sources

- **NIBE ModbusManager 1.0.9 exports**, database 9696: register definitions and factory defaults for the bus models.
- **Register exports from S-series pumps**, as collected in the nibe library (<https://github.com/yozik04/nibe>, `nibe/data`), and that library's hand-made corrections in `extensions.json`. The nibe library is distributed under the GNU GPL v3 (its `LICENSE`; its package metadata says LGPL v3).

## Your own export

To add a model these tables lack, convert your own ModbusManager or S-series export with the same code (`thermaestro.nibe.maps.build`) and load the result with `thermaestro.nibe.maps.load_file`.

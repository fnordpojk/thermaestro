# Thermaestro gateway

The gateway between a heat pump's serial bus and Thermaestro, for a Linux machine with an RS485 adapter. It is under development, and nothing is usable yet.

Version 0.0.0 on PyPI is a placeholder that keeps the package name. The project lives at https://github.com/fnordpojk/thermaestro.
